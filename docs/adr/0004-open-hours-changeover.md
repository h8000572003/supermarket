# 營業時段可換貨（修訂 ADR 0003）

ADR 0003 規定營業時段只開放打烊即結束的暫時性指令，理由之一是格位突然改變會讓顧客與補貨中的店員面對不一致的狀態。我們仍允許店長在營業時段更換格位的商品，但改由店員逐步完成：先下架（舊陳列庫存全部取下、退回倉庫），下架的那一刻格位才改成新商品且為空，新商品再照一般補貨上架；下架前舊商品照賣。因為變化由店員的動作驅動，畫面與模擬中不會出現格位突然改變。打烊時尚未完成的換貨直接以準備階段的規則完成（舊商品退回倉庫、格位改成新商品），所以 ADR 0002 的存檔格式不變。替代方案是維持營業中完全不能換貨，或讓換貨立即生效；前者讓店長面對冷門商品佔位整天無計可施，後者正是 ADR 0003 想避免的突然改變。準備階段的更換格位商品仍立即生效。
