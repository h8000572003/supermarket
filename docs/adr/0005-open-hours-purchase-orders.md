# 營業時段可下進貨單，18:00 截單（修訂 ADR 0003）

ADR 0003 規定營業時段只開放打烊即結束的暫時性指令，下進貨單只能在準備階段進行。我們改為營業時段中也可下一般進貨單，但遊戲內 18:00（含）之後當天截單；當天下的單（不論準備階段或營業中）都在下一個營業日開店前送達倉庫，第 1 天的開幕進貨仍當天立即送達。營業中下的單不改變當天的店面與庫存，所以不會出現 ADR 0003 想避免的突然改變；費用、運費與最低訂購量與準備階段相同，張數不限，下單後不能取消或修改。每張單下單時即記下自己的送達日，送貨只看這個日期，日後改變送貨規則也不影響已在途的單。依 ADR 0002，營業中途離開會連同當天營業中下的單與其付款一起回到準備階段。替代方案是截單後仍接單但改為後天送達；那需要玩家同時追蹤兩批在途貨，且與緊急叫貨的用途重疊，因此截單後只能改用緊急叫貨或等下一個營業日。
