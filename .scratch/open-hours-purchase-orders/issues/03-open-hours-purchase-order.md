# 03: 營業中下進貨單與 18:00 截單

**What to build:** 營業時段中，遊戲時刻 18:00 前可以下一般進貨單，送達日 = 今天 + 1；18:00（含）之後回傳 `order-cutoff`（「18:00 之後今日已截單，可改用緊急叫貨」）。費用、運費、最低訂購量、資金檢查都與準備階段相同，張數不限，並計入當天每日結算的進貨支出。進貨面板（桌機表格與手機卡片）營業中可以編輯數量並下單：18:00 前顯示「18:00 截單・明天開店前送達」，之後停用並提示改用緊急叫貨；營業中說明文字改為只說售價要在準備階段調整。「已訂未到」數量包含營業中下的單。

規格：`.scratch/open-hours-purchase-orders/spec.md`（使用者故事 1–11、14–18、24；ADR 0005）

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 營業中 17:59 下單成功、扣款、出現在 `pendingOrders`，隔天開店前送到；當天倉庫不變
- [ ] 18:00 與之後下單被拒（`order-cutoff`），每日結算階段仍被拒
- [ ] 營業中資金不足、最低訂購量、未解鎖都被拒
- [ ] 第 1 天營業中下的單隔天送達；準備階段行為不變
- [ ] 營業中下的單計入當天每日結算的進貨支出
- [ ] 進貨面板營業中可下單；18:00 後停用並提示；說明文字更新；手機與桌機都可用
- [ ] 既有平衡守門測試通過，`npm run balance` 結果不變
