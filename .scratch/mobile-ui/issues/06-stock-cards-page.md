# 06: 商品與進貨的全螢幕卡片頁

**What to build:** 新增共用元件 `FullScreenPage`（左上角返回鍵、底部固定列）與 `Stepper`（− 數值 ＋，數值欄位為 `inputmode="numeric"`）。窄版版面下，「商品與進貨」以 `FullScreenPage` 打開，每個商品是一張卡片：
- 收合時顯示名稱、類別、倉庫／在途數量、售價（低於建議售價為綠，高於為紅）。
- 展開時有售價與訂購量的 `Stepper`，並列出進價與建議售價；營業中再加上限時特價。
- 頁首有類別分頁，未解鎖的商品排在最後並顯示為灰色。
- 底部固定「小計＋運費＝合計｜下單」；營業中的緊急叫貨區段放在頁內。

和寬版表格共用同一份訂單狀態與送出邏輯；寬版維持表格，數字輸入也改用 `Stepper`。

規格：`.scratch/mobile-ui/spec.md`（使用者故事 31–39）

**Blocked by:** 01, 04

**Status:** ready-for-agent
