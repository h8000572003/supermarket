# 02: 觸控手勢、鏡頭與點擊判定

**What to build:** 在 `src/render/scene.ts` 加入平移偏移，`layout()` 改成「置中 + pan」，平移範圍要有限制。支援雙指縮放（以兩指中點為縮放中心）與單指／滑鼠拖曳平移；移動超過約 8px 才算拖曳，拖曳後不觸發點擊。新增「重設視角」按鈕與 `resetView()`，並對外提供「讓某個設施露在指定螢幕區域內」的平移 API，供 03 的抽屜呼叫。直向時預設縮放改成店面寬度貼齊螢幕。點擊時先判定是否點到設施 sprite（由前往後），點到就選取那個設施，沒點到才判定地板格。滾輪縮放、右鍵取消照舊。
