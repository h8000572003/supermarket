# 04: 精簡 HUD、底部工具列與提示訊息

**What to build:** 窄版版面下，HUD 改成約 44px 的狀態列：「第 N 天 · 時間 · 資金」，加上主要按鈕（準備階段為「開店」，營業中為倍速切換）。「目標」「音效」「新遊戲」收進「⋯」選單；點狀態列可展開口碑、店內人數與今日營收。準備階段的工具列改成一排：選取、一般貨架、冷藏櫃、收銀台、商品與進貨（保留在途數字徽章）、店員；「店員」打開 03 的 `BottomSheet`，在裡面雇用／解雇並顯示日薪。營業中的工具列為「商品與進貨」與派工說明。提示文字縮成一行；觸控模式下不顯示左鍵、右鍵、R、Esc 等說明。提示訊息固定在工具列上方，3 秒後自動消失，錯誤用紅色。橫向手機時，狀態列在上方，工具列改到右側直排。寬版版面的 HUD 也一起換新外觀，但保留全部資訊。
