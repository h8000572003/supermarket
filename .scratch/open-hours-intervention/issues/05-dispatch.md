# 05: 派工

**What to build:** 營業中，店長在場景點擊陳列櫃的格位或收銀台，選單多一個「優先處理」，即可派工；被標記的目標在場景中有可辨識的標示，也可取消。同時最多 2 個派工標記。店員選擇工作的優先序變為：有人排隊的收銀台 > 派工標記 > 一般補貨，由最近有空的店員去做。格位派工會把該格位補滿，不受補貨門檻限制；倉庫沒貨時拒絕並說明原因。收銀台派工讓一位店員到該收銀台待命，直到隊伍清空後解除。完成後標記自動清除；打烊時全部清除。

規格：`.scratch/open-hours-intervention/spec.md`（使用者故事 28–36）

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 準備階段派工被拒；營業中可用
- [ ] 對陳列庫存仍高於補貨門檻的格位派工，店員會去倉庫取貨並補滿該格位，之後標記清除
- [ ] 對收銀台派工，會有店員前往該收銀台；隊伍清空後恢復自動工作
- [ ] 第 3 個派工標記被拒；倉庫沒貨的格位派工被拒並有原因
- [ ] 有人排隊的收銀台仍優先於派工標記
- [ ] 取消派工後店員恢復自動工作；打烊後沒有殘留的標記
- [ ] 場景中可看出被標記的格位或收銀台；`npm test`、`npm run lint`、`npm run build` 通過
