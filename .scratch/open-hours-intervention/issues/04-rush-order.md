# 04: 緊急叫貨

**What to build:** 營業中，店長可在「商品與進貨」面板下緊急叫貨：明細格式與最低訂購量同一般進貨單，下單即付款，運費為一般運費兩倍，下單後 2 遊戲小時送達倉庫，之後店員照常補上架。每天 1 次、22:00 後不可下單、資金不足拒絕，皆顯示原因。面板顯示預計送達時間與今日剩餘次數。打烊前未送達的，改於下一個營業日開店前送達；鮮食以實際送達日作為批次送達日。存讀檔後付了錢的緊急叫貨不會遺失。每日結算新增「緊急叫貨運費」一列，商品成本併入進貨成本。

規格：`.scratch/open-hours-intervention/spec.md`（使用者故事 18–27、54、56、59；ADR 0002、0003）

**Blocked by:** 02（營業中面板與指令檢查）

**Status:** ready-for-agent

- [ ] 準備階段下緊急叫貨被拒；營業中可用
- [ ] 下單時扣除商品成本加兩倍運費
- [ ] 下單 2 遊戲小時後倉庫數量增加，並發出「緊急叫貨送達」通知
- [ ] 同一天第 2 次、22:00 之後、資金不足、低於最低訂購量皆被拒並有原因
- [ ] 打烊前未送達者於下一個營業日開店前送達；鮮食批次的送達日正確
- [ ] 進入準備階段後存讀檔，未送達的緊急叫貨仍會送達（存檔測試）
- [ ] 每日結算有「緊急叫貨運費」一列，數字與當天下單一致
- [ ] `npm test`、`npm run lint`、`npm run build` 通過
