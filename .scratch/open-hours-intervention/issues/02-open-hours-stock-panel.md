# 02: 營業中可開啟「商品與進貨」面板（前置重構）

**What to build:** 為營業中的指令鋪路，玩家行為幾乎不變。營業中可以打開「商品與進貨」面板查看商品、倉庫數量與售價，但售價與一般進貨單顯示為鎖定、無法操作。sim 端新增共用的「只在營業時段可用」指令檢查與對應的錯誤碼（與既有的「只在準備階段可用」對稱），供後續的限時特價、緊急叫貨使用；介面能把這個錯誤碼顯示成中文訊息。

規格：`.scratch/open-hours-intervention/spec.md`（使用者故事 7、16；ADR 0003）

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 營業中可開啟面板，售價輸入與一般進貨單為鎖定狀態，並有說明（例如「營業中只能使用限時特價與緊急叫貨」）
- [ ] 準備階段的面板行為與現在完全相同
- [ ] 準備階段指令在營業時段仍被拒（既有測試仍通過）
- [ ] 新錯誤碼有對應的中文訊息
- [ ] `npm test`、`npm run lint`、`npm run build` 通過
