# 01: 滿意度新公式與重新平衡

**What to build:** 讓降價有實際好處。一次無扣分的購物，滿意度基準改為 85；每件以低於建議售價成交的商品依折扣幅度加分，整次購物加分上限 15，最後仍限制在 0–100。缺貨、嫌貴、店裡沒賣、排隊的扣分，以及空手離開、放棄的規則不變。重新決定口碑里程碑「街坊好評」的門檻，讓標準經營仍在兩週左右達成。玩家在遊戲中可觀察到：全面略低於建議售價時，口碑上升得比照建議售價快。

規格：`.scratch/open-hours-intervention/spec.md`（使用者故事 1–6、62）

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 售價高於建議售價時，購買機率規則不變（既有測試仍通過）
- [ ] 以 `Game` 跑一天：同種子下，全面打 9 折的店平均滿意度高於照建議售價的店
