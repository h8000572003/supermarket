# 02: 換貨中的更改與清空

**What to build:** 換貨下架前，店長再次更改同一格位：改回原商品即取消換貨；改成第三種商品只更新換貨目標。格位陳列庫存為 0 時更換立即生效、不建立換貨。營業中也能把格位改成不指定商品：一樣先下架，下架後格位不指定商品，面板顯示「換貨中：舊商品 → 清空」。

規格：`.scratch/open-hours-changeover/spec.md`（使用者故事 5、11–13）

**Blocked by:** 01（換貨主流程）

**Status:** ready-for-agent

- [ ] 下架前改回原商品：換貨取消，舊商品仍在架上
- [ ] 下架前改成第三種商品：只更新換貨目標，下架後格位為第三種商品
- [ ] 陳列庫存為 0 時更換立即生效，沒有換貨目標
- [ ] 換成不指定商品：下架後格位不指定商品；面板顯示「→ 清空」
- [ ] `npm test`、`npm run lint`、`npm run build` 通過
