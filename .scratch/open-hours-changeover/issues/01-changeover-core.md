# 01: 換貨主流程

**What to build:** 營業中，店長可以在格位選單更換格位的商品，格位進入換貨。下架前舊商品照賣、不再被補貨。店員依「有人排隊的收銀台 ＞ 派工 ＞ 下架 ＞ 一般補貨」的順序前來下架，一趟取下全部舊商品；取下的那一刻格位改成新商品且為空，舊商品搬回倉庫（保留原批次），之後新商品照一般補貨上架。同一格只會有一位店員下架。打烊時尚未下架的換貨直接完成，店員手上搬的舊商品退回倉庫。準備階段更換格位商品仍立即生效。手機抽屜與桌機面板在營業中都提供格位選單，換貨中顯示「換貨中：舊商品 → 新商品」。

規格：`.scratch/open-hours-changeover/spec.md`（使用者故事 1–4、6–10、14–20、24–31、33；ADR 0004）

**Blocked by:** None (can start immediately)
