# 03: 派工到換貨中的格位

**What to build:** 對換貨中、尚未下架的格位派工時，最近有空的店員先去下架，再把新商品補滿，完成後才清除派工標記。換貨中的格位即使舊商品還滿架也能派工；派工的「倉庫沒有貨」檢查改看換貨目標（新商品）。

規格：`.scratch/open-hours-changeover/spec.md`（使用者故事 21–23）

**Blocked by:** 01（換貨主流程）

**Status:** ready-for-agent

- [ ] 舊商品滿架、換貨中的格位可以派工
- [ ] 派工後店員先下架，接著補滿新商品，完成後標記清除
- [ ] 倉庫沒有新商品時派工被拒並說明原因（即使倉庫有舊商品）
- [ ] 沒有換貨的格位派工行為不變（既有派工測試通過）
- [ ] `npm test`、`npm run lint`、`npm run build` 通過
