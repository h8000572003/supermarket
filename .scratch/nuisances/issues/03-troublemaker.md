# 03: 奧客

**What to build:** 第 3 個營業日起，開店排程時以一定機率排定今天奧客出現的時刻（每天最多 1 位，與狀況排程分開）。奧客從入口進來，在店內四處走動，不買東西也不排隊，不算顧客。在場時來客速率 ×0.85；除了共通的滿意度扣分，在他附近（約 3 格內）待過的顧客離店時再扣一次。待一段長時間後自己離開；派店員勸離約 5 遊戲分鐘，可讓他提早走。走向出口期間不再算在場。

規格：`.scratch/nuisances/spec.md`（使用者故事 16–19）

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 第 1、2 天不出現；第 3 天起每天最多 1 位，出現時刻由種子亂數排定
- [ ] 奧客是獨立的移動代理，不是顧客：不帶購物清單、不進隊伍、不計入顧客人數、滿意度平均與顧客類型統計
- [ ] 附近約 3 格內待過的顧客，離店時額外扣一次滿意度
- [ ] 到時間自行離開；勸離處理完成後提早離開；走向出口期間不再降來客速率或扣分
- [ ] 來客倍率 ×0.85
- [ ] 奧客 sprite 與圖示；點擊能點中並派工
- [ ] `npm test`、`npm run lint`、`npm run build` 通過
