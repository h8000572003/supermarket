## Comments

調整後的數值（`src/sim/nuisances/nuisances.ts`）：

- 顧客每走進一個新格子掉垃圾的機率 `LITTER_CHANCE_PER_TILE = 0.003`（初值 0.001 每天不到 1 個；0.006 時標準經營每天約 16 個，太頻繁）。標準經營每天約 8–9 個麻煩。
- 老鼠、奧客：第 3 天起每天各 40% 機率出現，時刻 08:00–20:00。
- 來客倍率：垃圾 ×0.95、老鼠 ×0.8、奧客 ×0.85；滿意度扣分：垃圾 5、老鼠 15、奧客 10（附近 3 格內再扣 10）；處理時間 1／3／5 遊戲分鐘；奧客 90 遊戲分鐘後自行離開。
- 不在麻煩測試裡的測試（顧客類型、狀況效果、口碑、天氣）以 `GameOptions.nuisances: false` 關閉自然出現的麻煩，避免來客與滿意度被改變。

`npm run balance`（30 天、種子 1–3）：

- 麻煩放著不管 ÷ 標準經營的累計營收比：0.734、0.765、0.748；期末資金約 3.0–3.5 萬，標準經營約 6–7 萬。
- 既有斷言照樣通過，沒有放寬。
