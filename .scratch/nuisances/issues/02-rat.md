# 02: 老鼠

**What to build:** 第 3 個營業日起，開店排程時以一定機率排定今天老鼠出現的時刻（每天最多 1 隻，與狀況排程分開）。老鼠從倉庫門跑進店裡，在走道上隨機移動，不吃商品，也不會自己離開。在場時來客速率 ×0.8，顧客扣滿意度照共通規則。被派去的店員要追到老鼠當下的位置，再花約 3 遊戲分鐘抓到。畫出老鼠 sprite 與圖示。

規格：`.scratch/nuisances/spec.md`（使用者故事 12–15）

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 第 1、2 天不出現；第 3 天起每天最多 1 隻，出現時刻由種子亂數排定
- [ ] 從倉庫門進場，在走道格隨機移動；不擋路、不碰陳列庫存
- [ ] 店員追蹤老鼠的最新位置，追到後處理約 3 遊戲分鐘
- [ ] 來客倍率 ×0.8；滿意度扣分照共通規則
- [ ] 老鼠 sprite、移動動畫與圖示；點擊能點中移動中的老鼠
- [ ] `npm test`、`npm run lint`、`npm run build` 通過
