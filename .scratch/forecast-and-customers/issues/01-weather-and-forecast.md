# 01: 天氣與星期、明日預報

**What to build:** 每個營業日有天氣（晴、雨、熱、冷）與星期（平日、週末）。第 1 天固定晴、星期一；之後星期依天數循環，天氣由 Game 的 seeded RNG 產生，同一種天氣不會連續超過 3 天。準備階段同時知道今天與明天的天氣，進入下一天時明天變成今天、再產生新的明天。狀態列顯示今天的天氣圖示與星期（例如「☀ 週一」），準備階段顯示明日預報。存檔新增今天與明天的天氣，快照版本號遞增。本張不加任何遊戲效果（效果在 02）。

規格：`.scratch/forecast-and-customers/spec.md`（使用者故事 1–3、8、9、12）

**Blocked by:** None (can start immediately)
