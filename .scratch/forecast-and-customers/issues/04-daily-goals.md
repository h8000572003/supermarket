# 04: 每日目標

**What to build:** 第 2 天起，每天進入準備階段時從目標池挑一個每日目標，挑選時參考今天的天氣與星期，避開未解鎖或沒有陳列的類別，目標數字依店況調整到可達成範圍（例如：賣出某類別 N 件、當天沒有顧客因缺貨空手離開、當天報廢為 0、結帳人數達 N）。打烊時判定，達成發放資金（約 $500–1,500）或口碑 +2，沒達成不扣分。狀態列與「目標」面板顯示今天的目標與進度，與里程碑分區；每日結算顯示結果與獎勵。存檔新增今天的每日目標，快照版本號遞增。

規格：`.scratch/forecast-and-customers/spec.md`（使用者故事 21–27）

**Blocked by:** 01（天氣與星期）

**Status:** ready-for-agent

- [ ] 第 1 天沒有每日目標；第 2 天起每天恰好一個
- [ ] 目標只涉及已解鎖且有陳列的類別；熱天會出現飲料相關目標的機會較高
- [ ] 打烊時判定：達成時資金或口碑增加，沒達成不變；每日結算顯示結果
- [ ] 進度可讀，營業中隨銷售更新
- [ ] 存讀檔後每日目標相等；快照版本號遞增
- [ ] 狀態列與「目標」面板顯示每日目標，與里程碑分開（手動驗證）
- [ ] 平衡守門測試成立（策略不使用每日目標）
- [ ] `npm test`、`npm run lint`、`npm run build` 通過
